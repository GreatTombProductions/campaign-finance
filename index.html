About This Data

The Federal Election Commission requires disclosure of all individual contributions over $200 to federal candidates, parties, and political action committees. This tool makes that data searchable.

  • By Employer — See where employees of a company direct their political donations
  • By Zip Code — See the top political donors in any zip code
  • By Candidate — See who's funding a candidate and from which industries

All data is from publicly available FEC bulk downloads. This is a static lookup tool — no data is collected, no searches are tracked.
